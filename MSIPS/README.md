# MSIPS reproducibility companion

This folder contains the versioned research companion for Decision Specific Identity Evidence Selection for Smart Homes with Ledger Aware Placement.

The completed release includes scenario-aware worked cases, a 100–1000 candidate synthetic benchmark, forward greedy plus local search, an initialization experiment, a Matter-derived ACL illustration, generated inputs, verification scripts, and literature-search records. All numerical attack contributions are hypothetical; no household traces are published.
